## 2026-04-27 - v1.9: 发布脚本多tab修复+键盘话题输入+位置自动切换+精确定位选择✅
- **时间**: 2026-04-27 02:32
- **改动**:
  1. **页面选择修复**: 从 URL 匹配改为遍历找 `.editor-kit-container`，解决多 tab 选错页面问题（核心修复）
  2. **自动回复页面选择修复**: `.pop()` 改为遍历找有评论/私信界面的页面（v66）
  3. **话题输入修复**: `execCommand` 改为 `page.keyboard.type()` 逐个字符输入 + `Space` 键分隔，解决空格被吞问题；加入自动空格检测机制（检测失败自动补救）
  4. **位置扩展类型切换**: 写死坐标点击改为 `element.click()` 触发下拉菜单，自动检测当前类型是否需要切换为"位置"
  5. **位置输入框修复**: 找到 `semi-select-selection-placeholder` 或"输入地理位置"元素并点击，不再依赖写死坐标 (769,453)
  6. **位置精确匹配**: 优先选择"锦湖电脑数码城"（不带括号），跳过带括号的变体（如"南阳市卧龙区星源电子销售中心(锦湖电脑数码城店)"）
  7. **exec timeout 从 180s 改为 600s**：防止截图步骤超时被杀掉（SIGTERM）
  8. **Chrome 配置管理**: 正常 Chrome 配置复制到 `~/.openclaw/chrome-debug-profile` 保留登录态
- **文件**:
  - `scripts/douyin_auto_publish.js` (v1.7 → v1.9)
  - `scripts/douyin_auto_reply.js` (v65 → v66, 页面选择修复)
- **核心教训**:
  - 多 tab 环境下不能用 URL 关键词猜页面，要检查页面实际 DOM 特征
  - 坐标点击不可靠，抖音页面布局会变化；`element.click()` 比 `mouse.click(x,y)` 稳定得多
  - `execCommand('insertText')` 注入空格不可靠，必须用 `keyboard.type()` + `keyboard.press('Space')`
