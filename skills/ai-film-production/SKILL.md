## 📁 项目存储规范

**所有 AI 电影/漫剧的素材和成品必须存放在** `projects/ai-films/` 目录下。

```
~/.openclaw/workspace/projects/ai-films/
│
├── <项目名>/                    # 每个项目一个独立文件夹
│   ├── references/              # 参考图（角色基准图×3 + 角色细节图×4-5 + 场景四视图×4 每场景）
│   ├── script/                  # 分镜脚本（.md）
│   ├── storyboards/             # 分镜图（豆包生成的 .png/.jpg）
│   ├── videos/                  # 单镜头视频（Agnes 图生视频输出 .mp4）
│   ├── audio/                   # 配音文件（.mp3 / .wav）
│   └── output/                  # 🎬 最终成片（preview.mp4 / final.mp4）
│
└── .template/                   # 项目模板目录
```

**每次新建项目时：**
1. 创建 `projects/ai-films/<项目名>/` 目录
2. 按上述结构初始化子目录（含 `references/`）
3. 所有中间素材归类存放
4. 最终成品放入 `output/`
5. 项目完成后 `git add` 提交

### 🎬 分镜复杂度自动判断规则（生成表前必读！）

输出提示词表之前，**必须对每个镜头做复杂度分析**，决定需要几张分镜图。

**核心原则：分镜图张数不设限，由导演级审美决定。**

判断依据：
- **动作跨度**：这个镜头里人物/物体经历了几个动作阶段？起点→终点之间需要几个关键帧来捕捉？
- **情绪变化**：表情/情绪有多大变化？是否需要特写帧来捕捉微表情转折点？
- **空间变化**：视角/构图变化幅度？从全景到特写是否需要中间过渡帧？
- **叙事节奏**：这个镜头在叙事上有多重要？高潮镜头值得更多帧来保证质感

**多图引导模式（v3.5.0 核心升级）：**
- 简单镜头（1 张图）→ 上传 1 张 → Agnes 生成 1 段视频
- 复杂镜头（N 张图）→ 上传 N 张到 Agnes 多图引导/关键帧模式 → Agnes 自动生成连贯过渡 → **1 段视频**
- **不需要**分别生成多段视频再后期拼接/交叉溶解

**典型参考（不是上限）：**
- 单一动作静态构图 → 1 张（如坐赌桌推银元、黎明空镜）
- 两步动作+微表情 → 2 张（如揭骰盅→瞳孔收缩）
- 多步骤动作+情绪崩溃 → 3-4 张（如跌撞进门→扶门框→跪倒→崩溃）
- 两人互动+空间转换 → 2-3 张（如从暗处走出→放下包袱→双人同框对话）

**拆分原则：**
- 每张图只描述那一帧的**静态姿态**，不塞整段动作
- A 图 = 动作起点 / 第一帧
- B 图 = 动作中段 / 转折点
- C 图 = 动作后半段 / 情绪顶点
- D 图（如有）= 终帧 / 落幅

### 🧠 AI 生图提示词三大核心原则（v4.4.0 新增）

**原则 1：规避关键词联想陷阱（提示词污染）**

AI 对某些抽象/刻板印象词汇有固定的联想模式，会导致生成结果偏离预期。

| ❌ 易污染的抽象词 | ✅ 具象替代描述 |
|------------------|----------------|
| `anxious expression`（焦虑表情） | `jaw tightened, eyebrows furrowed, lips slightly parted, knuckles white` |
| `scared`（害怕） | `eyes wide open, pupils dilated, shoulders hunched, fists clenched` |
| `beautiful woman`（美女） | `clear skin, symmetrical facial features, long straight black hair` |
| `muscular man`（肌肉男） | `broad shoulders, narrow waist, defined jawline` |
| `playing games`（打游戏） | `hands holding a phone horizontally, thumbs tapping on screen` |
| `romantic`（浪漫） | `soft warm light on both faces, they lean toward each other slightly` |
| `crying`（哭泣） | `tears streaming down cheeks, red-rimmed eyes, lower lip trembling` |

**铁律：写画面里实际能看到的物理特征，不写抽象情绪概念。**

**原则 2：利用视觉代偿机制控制镜头**

AI 不理解抽象的镜头指令（如"推近"、"俯拍"），但会通过画面中的**具体视觉元素**来代偿。

| 想要的镜头效果 | ❌ 抽象指令 | ✅ 视觉代偿写法 |
|--------------|------------|----------------|
| 推近/特写 | `close-up shot` | 多描述细节：`visible pores on skin, individual eyelashes, texture of the fabric` |
| 拉远/全景 | `wide shot` | 描述更多环境：`the entire room visible, furniture in background, window on the left wall` |
| 俯拍 | `bird's eye view` | 描述从上往下能看到的：`top of the head visible, shoulders below, floor pattern beneath` |
| 仰拍 | `low angle shot` | 描述从下往上能看到的：`chin and nostrils prominent, ceiling light above, sky in background` |
| 侧拍 | `side profile` | 描述侧面能看到的：`ear visible, one eye hidden behind the other, nose profile prominent` |

**铁律：想控制镜头角度/距离，就描述那个角度/距离下画面里**能看到的元素**，不写抽象的镜头术语。**

**原则 3：描述逻辑——聚焦画面可见元素**

写 prompt 时不要先构建空间再摆摄像机，而是**直接描述画面里能看到的具体视觉内容**。

| ❌ 错误写法（先搭场景再放摄像机） | ✅ 正确写法（直接描述画面内容） |
|-------------------------------|-------------------------------|
| `A room with a desk. Camera is positioned to show a man sitting.` | `A man sits at a wooden desk, his hands resting on scattered papers, warm lamplight on his face` |
| `A hallway. The camera looks down it toward a door.` | `A long narrow hallway stretches ahead, a closed wooden door at the far end under a flickering ceiling light` |
| `Two people in a room, shot from the side.` | `A man and woman face each other, warm light illuminating the man's left cheek and the woman's right profile` |

**铁律：prompt 里不要出现 `Camera is...`、`shot from...`、`positioned to...` 这类镜头搭建描述，直接写画面内容。**

**⚠️ 注意：这些原则适用于 Step 1 写分镜提示词表和 Step 4 生分镜图时的 AI prompt。图生视频（Step 5）的 Agnes prompt 仍然可以写镜头运动指令（如 `Camera slowly pushes in`），因为 Agnes video-v2.0 对这类指令有一定理解力。**

## 🎨 AI 真实感与电影感增强指南 (通用核心 v6.1)

> **说明**：本章节是提升视频质感的**底层审美标准**，**功能一（Agnes）和功能二（可灵）都必须遵守**。

### 1. 🔍 人物真实感 5 维度（拒绝塑料感）

每次生成视频前，**必须**检查以下 5 个维度的细节描述是否加入 Prompt：

#### ① 肢体动作 (Body Language)
- **拒绝**：呆板站立、机械挥手。
- **要求**：拆解动作细节，结合全身姿态。
  - *示例*："手指因用力抓紧背包带而指节泛白"、"肩膀下沉，深深叹气后颓然靠在沙发上"。

#### ② 皮肤细节 (Skin Details)
- **拒绝**：磨皮过度、像假人。
- **要求**：加入肤质、瑕疵、生理反应。
  - *示例*："可见皮肤毛孔"、"因思考眯眼产生的眼角自然细纹"、"额头渗出细密汗珠"、"熬夜带来的轻微黑眼圈"。

#### ③ 情绪控制 (Micro-expressions)
- **拒绝**：只有"开心"或"难过"这种大词。
- **要求**：描述情绪的**微过程**或**瞬间状态**。
  - *示例*："嘴角极短暂下压"、"眼神从散乱瞬间变得锐利"、"瞳孔放大，微微张嘴，呼吸急促"。

#### ④ 外表匹配人设 (Appearance Matching)
- **拒绝**：衣服像新买的，头发像刚做的造型。
- **要求**：加入生活痕迹、动态痕迹。
  - *示例*："灰色卫衣上有真实的褶皱和拉扯痕迹"、"丸子头松散微乱，几缕碎发贴在脸上"、"裤脚堆叠在鞋面上"。

#### ⑤ 运镜匹配情绪 (Camera & Emotion)
- **拒绝**：所有镜头都是固定机位或匀速平移。
- **要求**：运镜必须服务于情绪。
  - *示例*："迷茫时用手持晃动 (Handheld)"、"惊讶时用希区柯克变焦 (Dolly Zoom)"、"展示帅气时用环绕旋转 (Orbit)"。

### 3. 🎬 导演级大片镜头控制组合 (v6.2 新增)

> **核心理念**：不只是单个运镜，而是**“运镜组合”**，为了**“情绪节奏”**服务。

#### 📷 经典场景运镜包 (Scene Packages)

| 场景类型 | 镜头组合拳 (Combo) | 效果/情绪 | 示例 Prompt |
|---|---|---|---|
| **人物出场** | **低机位缓慢抬升** (Low Angle Slow Tilt Up) | 英雄气概、压迫感、霸气 | `Start from shoes, camera slowly tilts up to face, low angle, heroic entrance.` |
| **人物出场** | **背面缓慢扫视** (Back View Slow Pan) | 神秘、悬念、期待感 | `Filmed from behind, slow pan up, silhouette against bright light, mysterious.` |
| **情绪压迫** | **支配视角俯拍** (Dominant High Angle) | 危险、弱势、绝望 | `Shot from above (gunman's perspective), victim looks small and trapped.` |
| **心理失衡** | **斜角镜头** (Dutch Angle) | 不安、惊悚、眩晕 | `Tilted horizon, Dutch angle, uneasiness, psychological imbalance.` |
| **动作/街舞** | **地面视角 + 手持 + 快推** (Ground + Handheld + Push) | 命悬一线、炸裂、临场感 | `Ground level shot, handheld camera follows fast, rapid push-in, intense action.` |
| **宏大环境** | **鸟瞰/航拍** (Bird's Eye / Aerial) | 震撼、渺小、史诗感 | `Aerial view looking down, massive contrast between character and environment.` |
| **沉浸体验** | **POV / FPV** | 临场感、刺激、主观视角 | `First-person POV, walking through the corridor, seeing hands holding bag.` |

#### 🎥 拍摄法则 (Cinematography Rules)
*   **180 度法则**：在对话或双人镜头中，摄像机必须保持在角色连线的同一侧，防止空间关系错乱。*(Prompt 提示：`Maintain 180-degree rule, keep spatial consistency`)*
*   **30 度法则**：连续切换同一主体的镜头时，机位角度变化至少 30 度，配合景别变化（如中景切特写），保证画面衔接流畅。*(Prompt 提示：`Cut to close-up from a different angle (30-degree rule)`)*

#### 📸 构图指南 (Composition Guide)

> **核心理念**：构图决定了**“视觉重心”**，直接影响观众的情绪和注意力。

| 构图类型 | 适用场景与情绪 | Prompt 关键词示例 |
|---|---|---|
| **中心构图 (Center)** | 强调情绪、宿命感、孤独感 | `Centered composition, subject right in the middle` |
| **三分法 (Rule of Thirds)** | 自然舒展、呼吸感、通用 | `Rule of thirds, off-center placement, natural look` |
| **对称构图 (Symmetry)** | 秩序感、庄严、权力、压迫 | `Symmetrical composition, mirror image, imposing` |
| **对角线 (Diagonal)** | 运动感、爬楼梯、故事张力 | `Diagonal composition, leading lines, dynamic angle` |
| **引导线 (Leading Lines)** | 引导视线、延伸感、公路/走廊 | `Leading lines from corridor/fence leading to subject` |
| **框架式 (Frame in Frame)** | 压抑、窥视感、强调处境 | `Framed by doorway/window, looking through frame` |
| **前景式/脏构图 (Foreground)** | 沉浸感、空间纵深、遮挡 | `Blurred foreground element, looking past obstacles` |

#### 💡 导演级光影与布光指南 (Lighting Guide)

> **核心理念**：光影不仅照亮物体，更塑造体积感、情绪和人物气质。

| 布光类型 | 适用场景与情绪 | Prompt 关键词示例 |
|---|---|---|
| **顶光 (Top Light)** | 眼窝阴影、神秘、压迫感 | `Top lighting, shadows in eye sockets, mysterious vibe` |
| **侧光 (Side Light)** | 半明半暗、硬汉、内心冲突 | `Split lighting (Side light), half face in shadow, dramatic` |
| **逆光 (Back Light)** | 剪影、轮廓光 (Rim Light)、史诗感 | `Back lighting, rim light, golden outline, silhouette` |
| **伦勃朗光 (Rembrandt)** | 倒三角光斑、质感、深沉对话 | `Rembrandt lighting, triangle of light on cheek` |
| **硬光 (Hard Light)** | 边缘锋利、力量感、压抑 | `Hard light, sharp shadows, high contrast, raw` |
| **体积光 (Volumetric)** | 丁达尔效应、神圣、光路可见 | `Volumetric lighting, Tyndall effect, light beams` |

#### 📝 AI 提示词结构化原则 (VIDEO)
以后写提示词，**必须**涵盖以下 5 个维度：
1.  **V (Visual)**：场景、时间、光影。
2.  **I (Instruction)**：镜头角度、运镜方式。
3.  **D (Details)**：纹理、道具、外貌细节。
4.  **E (Emotion)**：心理状态、情感基调。
5.  **O (Output)**：分辨率、帧率、风格。

### 4. 🛠️ 如何在 Prompt 中调用？

*   **功能二 (可灵)**：直接融入自然语言描述。

### 📺 方案 A：Agnes 图生视频（免费预览）

> 适用于快速预览构图和动作，确认后再上可灵出高清版。

#### A.1 输入要求

1. 分镜图上传到 **freeimage.host** 拿到公网 URL
2. 不支持 base64
3. 图片尺寸建议 800px 左右

#### A.2 图生视频模式自动分析

每次图生视频前，**必须自动分析每个镜头适合的模式**，生成汇报表给主人确认：

| 分镜图数量 | 镜头特征 | 推荐模式 | 理由 |
|-----------|---------|---------|------|
| 1 张 | 静态/特写/单动作 | **单张生成** | 画面没有变化，单张足够 |
| 2+ 张 | 有动作递进/情绪变化 | **关键帧模式** | 帧 A → 帧 B 有明确时间线 |
| 2+ 张 | 纯参考维度（无时间线） | **多图引导模式** | 多张参考图提供不同维度 |

**汇报格式：**

```
🎬 图生视频模式分析报告

| 镜号 | 分镜图数 | 推荐模式 | 旁白内容 | 中文 Prompt | 理由 |
|------|---------|---------|---------|------------|------|
| 1A | 1 张 | 单张 | "我以为，是她在躲我。" | 镜头缓慢推近，男主翻抽屉看到照片 | 静态单动作 |
```

#### A.3 提示词确认机制（v4.7.2）

每次图生视频前，**必须同时提供中英文两份 prompt 给主人确认**：

```
🎬 镜头 1A —— 图生视频 Prompt
📷 分镜图数量：1 张（scene_1A_1.png）
🎥 生成模式：单张图生视频

【英文版】（用于 Agnes API）
> Camera slowly pushes in from medium shot to close-up as the man pulls photographs from a drawer, fingers trembling slightly.

【中文版】（供主人确认）
> 镜头从中景缓慢推近到特写，男主从抽屉中翻出旧照片，手指微微颤抖。
```

#### A.4 三层 Prompt 结构（v4.7.0）

```
[Main] 核心画面描述（主体 + 动作 + 运镜）
[Constraints] 角色锁定 + 镜头风格 + 光影 + 情绪
[Prohibitions] 最多 3-5 个明确不要的内容
[Base] Stable shot, smooth natural motion, cinematic quality, no flickering, no distortion, face and body consistent
```

#### A.5 高级运镜词库（v4.7.0）

| 运镜名称 | 英文 prompt | 适用场景 |
|---------|------------|---------|
| **缓慢推近** | `Camera slowly pushes in from [wide/close-up] to [close-up/face]` | 情绪递进、发现真相 |
| **缓慢拉远** | `Camera slowly pulls back from [close-up] to [wide shot]` | 揭示全貌、孤独感 |
| **手持跟拍** | `Handheld camera follows from [front/behind/side], slight breathing motion` | 增强临场真实感 |
| **希区柯克变焦** | `Dolly zoom (Hitchcock zoom), background stretches and compresses while subject stays same size` | 心理冲击、天旋地转 |
| **荷兰角倾斜** | `Dutch angle, 15-degree tilted horizon` | 不对劲、黑化、犯罪现场 |
| **一镜到底** | `Long continuous shot, no cuts, seamless camera movement` | 紧张感、沉浸感 |
| **固定镜头** | `Static camera, locked off, no movement` | 静态对峙、平静 |

#### A.6 动作修饰词规范

| 推荐用词 | 避免用词 |
|---------|---------|
| slowly, gently, smoothly, naturally, subtly | exaggerated, fast, violent, dramatic, extreme |
| slight trembling motion, breathing motion | shaking violently, rapid movement |

**核心原则：** 动作描述以正常或偏缓慢为主，避免模型加速导致画面混乱。

   - 示例：`0-3s 中景，@小葵 面部特写… 4-9s @男主 在 @舞室 跳舞… 9-11s 切 @男主 面部特写，表情从惊讶变开心`
2. **@主体引用**：@角色 + @场景 + @道具 全部可引用，全片一致性
3. **段间视频衔接**：生成下一段时，将上一段的最后画面导入作为首帧参考，从那个画面继续演

#### C.3 分镜脚本格式（v6.3 导演精确控时版）

**核心格式**：
```
[时间段]，[景别]，[视角/运镜]，@主体 动作/表情描述。
[时间段]，[景别]，[视角/运镜]，@主体 动作/表情描述。旁白说"台词"。
...
```

**每行要素**：
- **时间段**：`0-3s` / `4-9s` / `9-11s`（精确到秒，累计不超过 15s）
- **景别**：大全景 / 全景 / 中景 / 近景 / 特写
- **视角/运镜**：仰拍 / 俯视 / 缓慢推近 / 快速切镜 / 手持跟拍
- **主体**：`@角色名` / `@场景名`（必须用 @ 引用）
- **动作/表情**：描述画面里能看到的**物理特征**（遵守三铁律）
- **台词**：`旁白说"台词"` 或 `@角色 说"台词"`

**⚠️ 三铁律适用于功能二**：
1. 无抽象情绪词 → 写物理特征（不用 anxious/scared，用 eyebrows furrowed / jaw clenched）
2. 无抽象镜头指令 → 用角度下可见元素代偿（不用 close-up，用 face fills the frame）
3. 直接写画面内容 → 先写人/物再带环境

#### C.4 分镜脚本示例

**《寻舞》寻路迷茫段（15s）**：
```
0-4s，全景→中景，仰拍→平视缓慢下摇。@锦湖数码城招牌 红色大字占据画面上方，黄色箭头指向右侧通道，镜头下摇到 @小葵 站在招牌下举手机转圈，丸子头松散几缕碎发贴脸颊，眉头紧锁咬下嘴唇下巴可见，烈日直射刺眼眯眼，行人匆匆从两侧走过。旁白说"找了好几个地方，都没找到。"

4-8s，中景，框架构图，固定。@小葵 推开棕色铁栅栏门，头顶红色铁皮顶棚，两侧白墙挤压视线，手指死死抓着黄色背包带指节泛白，肩膀微缩脚步迟疑，顶光在眼窝处投下阴影。

8-11s，大全景切特写，平视偏高。@小葵 站在空旷水泥停车场中间显得非常渺小，橘红色建筑在远处，烈日下地面泛白反光，切面部特写——眉头紧锁，眼角因眯眼产生细纹，眼神四处乱飘找路牌，胸口深呼吸起伏。旁白说"导航说就在这附近，但我什么都看不到。"

11-15s，中景切特写，平视→仰视缓慢上摇。@小葵 走到 @红蓝墙裙1单元 墙裙下，抬头看蓝色门牌时下巴和鼻孔从下方可见，吞咽口水，手慢慢伸向生锈的楼梯扶手手指微微发抖。
```

**双人对话（10 秒）**：
```
0-3s，中景，@男主 和 @女主 面对面坐在老式绿皮火车的座位上，火车向前行驶中。切镜，特写 @男主 的侧脸，托着下巴，看向窗外，问，"Where are we about to go?"
3-6s，切镜，特写，@女主 的正脸，她看着 @男主 说，"We are about to go to a place where it is summer all year round."
6-8s，切镜，中景，@男主 笑着点了点头，说"I love summer"。
8-10s，切远景，@男主 和 @女主 两人面对面，对视微笑。
```

#### C.5 操作步骤（手机可灵）

1. 创建所有需要的主体（角色 + 场景 + 道具）
2. 打开可灵 → 选择「视频 3.0 Omni」模式
3. 绑定所有用到的主体（@角色 / @场景 / @道具）
4. 在「创意描述」框中粘贴完整分镜脚本（精确到秒的时间轴格式）
5. 设置参数（1080p，15s）
6. 开启「音画同步」（旁白短剧推荐开）
7. 点击「生成」

#### C.6 段间视频衔接（保证全片连贯性）

**核心逻辑**：段1 生成完后，导出段1最后 1-2 秒的画面，作为段2 的输入首帧参考，让段2从段1的结尾画面继续演。

**操作步骤**：
1. 段1 生成完成，导出视频
2. 截取段1 最后 1-2 秒的画面作为截图（或用视频最后一帧）
3. 段2 生成时，在可灵中**上传这张截图作为首帧参考图**
4. 分镜脚本从段1结尾的状态继续描述
5. 依次类推，段2→段3→段4 全部衔接

**示例（《寻舞》段1→段2衔接）**：
- 段1（0-15s）最后3秒：@小葵 站在楼梯口手扶栏杆吞咽口水
- 截取最后画面：小葵在昏暗楼梯口手扶栏杆的特写
- 段2（15-30s）开头描述：@小葵 站在昏暗楼梯口，手推白色实心门…（承接段1结尾）

#### C.7 与现有工作流的衔接

- 可灵开音画同步 → **跳过 Step 6**（旁白已包含在视频中）
- 可灵关音画同步 → **保留 Step 6**（用 Qwen3-TTS 后期配音）
- 4 段生成完后用 ffmpeg 拼接 + 交叉溶解转场（Step 7）
- 输出文件存入 `videos/segment_*.mp4`，最终成品存 `output/<项目名>.mp4`

### Step 7: 三层混音 + 剪辑拼接 + 发布

**第一视角旁白短剧的核心——三层音频混合：**

| 音频层 | 来源 | 音量比例 | 说明 |
|--------|------|----------|------|
| **环境音** | Agnes 视频自带 | 120% | 视频原始环境声（赌馆嘈杂、脚步等） |
| **旁白** | Qwen3-TTS | 300% | 主角/叙事者旁白，稍微大一点点 |
| **BGM** | 自动生成/自选 | 80% | 氛围背景音乐，连续铺满全片 |

**混合命令：**
```bash
ffmpeg -y \
  -i ambient_mixed.wav \          # 环境音拼接
  -i narration_spaced.wav \       # 旁白（带间隔）
  -i bgm.wav \                    # BGM
  -filter_complex "\n    [0]volume=1.2[amb]; \
    [1]volume=3.0[nar]; \
    [2]volume=0.8[bgm]; \
    [amb][nar]amix=inputs=2[a1]; \
    [a1][bgm]amix=inputs=2[a2]" \
  -map "[a2]" audio/final_mix.wav
```

**镜头间隔处理：**
- 每段旁白之间加 **1.3 秒静音**，让旁白节奏跟画面匹配
- 使用 `concat` + 静音文件实现

**转场处理：**
- 镜头之间加 **0.5 秒交叉溶解**（xfade fade transition）
- 不同镜头的分辨率需要统一后再转场

**发布：**
- 抖音发布 → 使用 `douyin-auto-ops` skill
- 小红书发布 → 使用 `xhs-auto-publish` skill

### Step 8: 视频拼接 + 加字幕 + 加 BGM

**拼接（同镜头多帧之间用交叉溶解）：**
```bash
# 同镜头的 A/B 视频之间用 0.3s cross-dissolve 过渡
# 不同镜头之间直接硬切（cut），保持节奏感
ffmpeg -i scene2A_final.mp4 -i scene2B_final.mp4 \
  -filter_complex "[0:v][1:v]xfade=transition=dissolve:duration=0.3:offset=$(echo "$(ffprobe -v error -show_entries format=duration -of csv=p=0 scene2A_final.mp4) - 0.3" | bc)[v]; [0:a][1:a]acrossfade=d=0.3[a]" \
  -map "[v]" -map "[a]" scene2_merged.mp4
```

**全部拼接：**
```bash
cat > /tmp/film_files.txt << EOF
file '/path/to/scene1_final.mp4'
file '/path/to/scene2_merged.mp4'
file '/path/to/scene3_merged.mp4'
file '/path/to/scene4_final.mp4'
file '/path/to/scene5_merged.mp4'
file '/path/to/scene6_merged.mp4'
file '/path/to/scene7_final.mp4'
EOF

ffmpeg -f concat -safe 0 -i /tmp/film_files.txt -c copy /tmp/film_merged.mp4
```

**加配音：**
```bash
ffmpeg -i scene1.mp4 -i scene1_voice.mp3 \
  -filter_complex "[1:a]adelay=300|300[a1]; [0:a][a1]amix=inputs=2:weights=0.2 1:duration=longest[aout]" \
  -map "0:v" -map "[aout]" -c:v copy -c:a aac -shortest scene1_final.mp4
```

**加 BGM：**
```bash
ffmpeg -i film_merged.mp4 -i bgm.mp3 \
  -filter_complex "[0:a][1:a]amix=inputs=2:weights=1 0.3" \
  film_final.mp4
```

**加字幕：**
```bash
ffmpeg -i film_final.mp4 \
  -vf "drawtext=text='欢迎光临！':fontsize=36:fontcolor=white:x=(w-text_w)/2:y=h-th-30:box=1:boxcolor=black@0.5:enable='between(t,0,5)'" \
  -c:a copy film_with_subs.mp4
```

## 🎨 场景大基调一致性指南

> **核心原则：基调词 = 全局常量，只有主体和镜头在变。**

同一部片子的所有分镜图，色调、光线、氛围必须统一。以下是实操方法：

### 方法 1：先出「场景基调图」（必须）
Step 3 生成的纯环境参考图就是基调锚点。后续每张分镜 prompt 的基调关键词必须跟这张图一致。

### 方法 2：基调词锁定表
项目开始时，在提示词表最前面写一段**基调定义**，例如：
```
【本片基调】
光线：逆光 backlit，金色轮廓 rim light
色温：暖金暖琥珀 warm golden amber tones
对比：高对比 high contrast
时间：傍晚黄昏 golden hour sunset
空气：轻微朦胧 hazy atmosphere，尘埃光柱 dusty sunbeams
镜头：35mm 叙事广角为主，特写可用 50mm
风格后缀：cinematic, photorealistic, film still, color graded
```
生成每个分镜时，这段基调定义**逐字复制**到 prompt 里，只替换主体描述和景别。

### 方法 3：提示词表检查
提示词表的"AI 提示词"列，每行的前半段（基调常量部分）应该**完全一致**。扫一眼就能发现跑偏的行。

### 方法 4：生成后拼图肉眼检查
所有分镜图拼成网格图，一眼看过去：
- ✅ 色调统一、光线方向一致 → 通过
- ❌ 某张明显"跳出来" → 删掉重跑

### 方法 5：Prompt 组装公式
每个分镜的完整 prompt = **基调常量 + 场景变量 + 风格后缀**：
```
[基调常量] + [主体描述/动作/景别] + [风格后缀]
```
