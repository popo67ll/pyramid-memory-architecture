## 舞室基本信息

- **抖音账号**：南阳嗨舞工作室
- **地址**：南阳市车站路与工业南路交叉口·锦湖电脑城院内5楼，没有电梯
- **微信**：瑶瑶老师 15083388123（仅私信给，评论区不给）
- **老师**：瑶瑶老师（各种风格爵士+KPOP）、刘祺老师（编舞+HipHop）
- **舞种**：爵士、KPOP、编舞、HipHop、Heels、Afro
- **非固定课表**：Heels 和 Afro 有开课，但上课时间不固定，有人问就说"有的，具体上课时间请咨询瑶瑶老师"
- **体验课**：9.9元一节，一个半小时
- **少儿**：4-12岁少儿舞蹈班

## 文件说明

| 文件 | 用途 |
|------|------|
| `课程表.md` | 每周课程安排（含时间/舞种/内容） |
| `价格总表.md` | 标准价、活动价、会员须知、体验课规则 |
| `课程表.png` | 课程表原图 |

## 使用场景

1. **主人询问课程** → 读取 `课程表.md` 回答
2. **主人询问价格** → 读取 `价格总表.md` 回答（注意活动期判断）
3. **主人发舞室资料** → 询问是否需要归档到此目录
4. **抖音自动回复** → 由 `douyin-auto-ops` 脚本动态读取本目录文件

## 注意事项

- 评论区绝对不给微信号，只能引导私信
- 评论区不说"没有电梯"
- 评论区不暴露老师真实名字
- 活动期（五一等）优先报活动价，非活动期报标准价
