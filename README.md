# 金字塔记忆架构（Pyramid Memory Architecture）

> 通用 AI Agent 记忆架构 Skill，适用于所有新建子 Agent 工作区初始化。
> 版本：v2.7

## 🚀 快速开始

### 方式一：一键初始化（推荐）

```bash
./scripts/init.sh my-new-agent
```

Windows 用户：
```powershell
.\scripts\init.ps1 my-new-agent
```

### 方式二：手动复制

将 `templates/` 目录下的文件复制到你的工作区：

```
workspace-{name}/
├── AGENTS.md          ← 顶层铁律
├── MEMORY.md          ← 业务规则
├── SOUL.md            ← 人格配置
├── IDENTITY.md        ← 身份卡片
├── USER.md            ← 主人信息
├── TOOLS.md           ← 本地配置
├── HEARTBEAT.md       ← 心跳清单
├── self-improving/    ← 自我进化
└── docs/              ← 详细文档
```

## 📐 架构总览

```
         ▲
        / \
       /   \
      / AGENTS.md \    ← 顶层：系统注入，铁律级行为规则（每次必加载）
     /-----------\
    / MEMORY.md   \    ← 中层：主会话加载，业务规则、触发器、长期记忆
   /---------------\
  /  SOUL.md 等      \  ← 中层：人格配置、心跳清单、身份信息
 /---------------------\
/  self-improving/     \ ← 按需读取：执行经验、错误纠正、领域教训
/-----------------------\
\   SKILL.md/TOOLS.md   / ← 底层：按需读取，技术实现细节、操作流程
```

| 层级 | 文件 | 加载方式 | 放什么 |
|------|------|---------|--------|
| **顶层** | AGENTS.md | 系统注入，每次必加载 | 铁律级行为规则、安全红线 |
| **中层** | MEMORY.md | 主会话注入 | 业务规则、长期记忆 |
| **中层** | SOUL.md | 系统注入 | 人格、使命、行为准则 |
| **中层** | HEARTBEAT.md | 心跳触发 | 待办提醒、周期性任务 |
| **按需** | self-improving/ | 任务前读取 | 执行经验、错误教训 |
| **底层** | SKILL.md | 场景匹配 | 技术实现、操作流程 |

## 📝 如何添加新规则

1. **判断类型**：行为规则 → AGENTS.md / 业务规则 → MEMORY.md / 技术细节 → SKILL.md
2. **生成锚点**：使用 `<!-- #领域-功能 -->` 格式（如 `<!-- #backup-database -->`）
3. **检查重复**：确认文件中没有相同规则
4. **写入文件**：锚点 + 规则内容
5. **更新引导**：如需引用，使用 `详见 [文件]「[章节名]」（#[锚点]）` 格式

### ⚠️ 铁律

- 新增/修改规则后，必须主动询问主人是否执行同步
- 引导方向只能从上往下（AGENTS → MEMORY → SKILL），禁止反向引导
- 锚点命名使用「领域-功能」格式，禁止裸写易冲突名称

## ❓ 常见问题

### Q: 版本历史要保留多少条？
A: 只保留最新 2 条。

### Q: 文件太大怎么办？
A: 单个 md 文件超过 3KB 时，考虑拆分到下层文件。

### Q: 如何检查规则有没有放错层级？
A: 每 3 天执行一次冗余检查（6 项清单 + 金字塔合规检查）。

### Q: 锚点断裂了怎么办？
A: 运行 `./scripts/check-anchors.sh <workspace目录>` 自动检测并修复。
